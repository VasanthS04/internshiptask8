# Predictive Churn Analysis
Logistic Regression vs Random Forest churn classifier on a synthetic customer dataset.

- `churn_model.py` - full reproducible pipeline (encode, split, train, evaluate, export)
- `churn_analysis.ipynb` - same pipeline as a notebook (runs in Google Colab)
- `REPORT.md` - method, results, interpretation, limitations
- `data/customer_churn_model_v2.csv` - input data
- `outputs/` - metrics, ROC curve, confusion matrix, feature importance, `churn_risk_scores.csv`

Run: `pip install -r requirements.txt && python churn_model.py`
